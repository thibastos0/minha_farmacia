Principais Funcionalidades
💻 Para o Munícipe
 Login Unificado: Integração via Cidadão ID / gov.br.
 Autocompletar Inteligente: Busca de medicamentos, CRM e médicos via API.
 Carrinho Multimedicamento: Envio de múltiplos itens vinculados à mesma receita.
 Rastreamento em Tempo Real: Acompanhamento do motoboy no mapa idêntico a apps de delivery.
🛡️ Para a Prefeitura & Farmacêutico
 Triagem Assistida por IA: Redução do tempo de análise de receitas.
 Gestão de Receitas Controladas: Protocolo de retenção e invalidação digital.
 Dashboard Gerencial:
 Tempo médio de atendimento e entrega.
 Indicadores de escassez de medicamentos.
 Geolocalização da frota de entregadores.
📦 Stack Tecnológica
 Mobile: React Native / Expo
 Backend / APIs: Node.js / Supabase / Firebase
 Automação & IA: n8n + OpenAI / Gemini Vision API
 Painel Web: React.js / Tailwind CSS
📄 Conformidade Regulatória e LGPD
 Anonimização de dados sensíveis de saúde conforme LGPD.
 Conformidade com normativas da ANVISA para validação remota de prescrições e retenção de controle especial.
